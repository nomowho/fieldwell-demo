# 巡好店 Fieldwell｜廠商展示版

藥局商化巡店工具的公開展示頁。先選通路品牌（大樹／佑全／安琪兒／美康），再選門市，支援店名、行政區及地址搜尋。

門市名稱與地址來自提供的 Excel：以 B 欄有序號且屬指定四通路的 109 筆為範圍（大樹 78、佑全 7、安琪兒 5、美康 19）。原檔未含 GPS，門市位置待設定。人員、商品、巡店、定位與績效成果為示範。

展示功能：巡店總覽、每日行程、巡店紀錄、定位稽核、異常追蹤、七項月度績效指標、CSV 匯出，以及現場巡店表單預覽。

新增巡店時先從下拉選擇 01 林盈岑或 02 黃再枝，再選通路與門市。巡店品牌可複選亞培、雀巢、惠氏、桂格，核心產品總排面以單一數字手動填寫；商品明細只在補貨、缺貨、近效期或退換貨時新增。

「定位稽核」可依日期、示範業務、通路、門市及狀態查看進出時間、停留分鐘、GPS 精度、距離門市與說明。Excel 未含門市座標，展示紀錄會維持「未核對」，不代表業務實際到店；正式版才會在進店、每張照片及離店取得手機 GPS，並由伺服器記錄時間。

新增「門市退貨」：查看每家門市填報的商品品牌、品名、退貨或換貨類型、數量、單位與原因；可依日期、通路、門市及商品品牌篩選，並匯出商品明細或門市品牌彙總。不同單位分開計算，舊的未分類退換貨不自動視為退貨。

在巡店表單填入商品後，按「完成預覽・查看退貨明細」可將本次模擬紀錄加入展示報表。商品品牌及部分品名參考使用者提供的畫面；示範數量與門市的配對不代表真實交易。

此頁為靜態展示；不需登入，不會提交定位、上傳照片或寫入正式資料庫。進店與離店時間、停留分鐘均為示範。表單、門市和狀態變更只在目前頁面記憶體內，重新整理後回復示範資料。

此儲存庫僅包含展示版編譯輸出；完整應用程式原始碼由擁有者另行管理。
